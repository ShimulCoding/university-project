# Security entry-point and trust-boundary map

Baseline: `816d7d6`, 2026-10-11. Prepared before vulnerability assessment. Local repository only; hosting, production configuration and production data are outside this review.

## Stack, roles and data stores

- Next.js 16 / React 19 / TypeScript / Tailwind frontend; Express 5 / Prisma 6 / PostgreSQL backend (`package.json`, both workspace manifests, `backend/prisma/schema.prisma:1`).
- Anonymous visitors: public events and approved financial snapshots. `GENERAL_STUDENT`: owned registrations, proofs and complaints. `SYSTEM_ADMIN`: global governance/oversight. Event assignments: `EVENT_ADMIN`, `EVENT_MANAGEMENT_USER`, `FINANCIAL_CONTROLLER`, `ORGANIZATIONAL_APPROVER`, `COMPLAINT_REVIEW_AUTHORITY` (`backend/src/utils/event-scope.ts:13`). Accounts may have no role while awaiting assignment. Active assignments are the operational authority.
- PostgreSQL tables/models (22): `User`, `Role`, `UserRole`, `EventTeamMember`, `RefreshToken`, `PasswordResetToken`, `Event`, `Registration`, `PaymentProof`, `Budget`, `BudgetItem`, `BudgetRequest`, `ExpenseRequest`, `ExpenseRecord`, `IncomeRecord`, `SupportingDocument`, `ApprovalDecision`, `Complaint`, `ComplaintRouting`, `ReconciliationReport`, `PublicSummarySnapshot`, `AuditLog`. Identity/PII, bcrypt hashes, hashed refresh/reset capabilities, memberships, Decimal financial records, revision/decision history, approved snapshots, document metadata and audit context.
- Private local evidence: `backend/src/config/uploads.ts:6` and `backend/src/storage/adapters/local-storage.adapter.ts:14`. The database contains paths/ownership; files are outside Next public assets and have random UUID names.
- Browser: HttpOnly access/refresh cookies (`backend/src/config/auth.ts:6`); short-lived PDF Blob URLs and browser font cache (`frontend/src/lib/pdf.ts:8`). Public fonts are static assets, not uploads.
- Process memory: rate-limiter counters, Prisma client, SMTP transporter, bootstrap flag. SMTP sends password-reset capabilities; development may use Ethereal (`backend/src/config/mailer.ts:9`). Stdout/stderr and AuditLog are additional data sinks.
- Repository/lockfile/tooling and ignored environment files are operator trust inputs. No hosting/firewall/backup/IaC or CI workflow was found in tracked files. No grades, refunds, waivers, payment-provider integration or inbound webhook implementation was found; those requested categories are not implemented features.

## Trust boundaries

1. Internet/browser → Next pages: URL/search parameters and cookies are untrusted. Server rendering forwards cookies to the configured API (`frontend/src/lib/api/server.ts:12`); browser fetches use credentials (`frontend/src/lib/api/client.ts`). React text/attribute rendering escapes text; no application `dangerouslySetInnerHTML`/`eval`/shell execution was found in the source inventory.
2. Browser/Next → Express: JSON, URL-encoded and multipart bodies, parameters, query, Origin, forwarded IP headers and User-Agent. Route Zod schemas validate body/query/IDs; two payment upload handlers parse schemas inside their controllers (`backend/src/modules/payments/controllers/payments.controller.ts:15`). Route authorization is followed by owning-event/owner checks in services.
3. Express → PostgreSQL: Prisma parameterized operations and `Prisma.sql` tagged queries in approvals/public repositories. Governance mutations and audit writes share serializable transactions (`backend/src/utils/governance-transaction.ts:12`); sign-in uses repeatable read.
4. Multipart → storage → protected response: user bytes/MIME/name/size cross the upload validator, storage provider and document authorization service. Document download is authenticated and parent-owned/event-scoped (`backend/src/modules/documents/services/documents.service.ts:61`).
5. Published snapshot → HTML/SVG/PDF: public mappers disclose approved aggregates/breakdown labels; text enters React and PDFKit text APIs. Raw PDF drawing commands are generated by application geometry, while labels use structured `PdfText` (`frontend/src/lib/pdf.ts:4`, `:53`, `:60`). PDF generation occurs in the browser, with a fixed four-font same-origin allow-list; there is no server HTML renderer or private PDF-export endpoint.
6. Authentication → SMTP/logs: password hashes and token hashes reside in the DB; raw reset token is delivered in the recovery URL. Request metadata and errors reach operational logs/audit. Credentials, PII and untrusted header/query text require special handling.
7. Operator → scripts/database: Prisma migrations and seed/demo scripts are CLI entry points. They are not HTTP routes and must not run against production as part of this audit.
